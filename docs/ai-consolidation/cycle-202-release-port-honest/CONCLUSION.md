# Native release port: honest-opponent validation

The frozen candidate passes this study's prespecified two-percentage-point
noninferiority gate. Both arms scored 322 wins, 3 draws and 59 losses in 384
games (84.24%), with no engine errors. Across 192 paired setup/seed units, the
candidate-minus-reference score interval is [-1.04, +1.04] percentage points;
its lower endpoint exceeds the frozen -2-point margin. Equal aggregate scores
do not establish identical decisions or universal policy equivalence.

This is a numerical/integration port comparison against Missions on the first
32 Army B records of each of the six seed-validation families. The candidate
uses its own Fortress deployment; the dataset does not replace that treatment.
The cohort is now consumed and must not be used for subsequent tuning.

Every saved attempt was replayed through the independent Python and native
referees, both policies have Qt6 captures, and the audit preserves all 768
attempts. The independent DOS endpoint and target qualification remain separate
mandatory release gates. This result alone does not authorize promotion.
