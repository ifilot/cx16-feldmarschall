# Cycle 28: no established general gain against an honest opponent

The native template policy scored 51.46% against the honest guarded student, compared with 50.00% for the native control. The paired difference was +1.46 percentage points, with a 95% interval of [-0.68, +3.61] and a retained 98.3333% interval of [-1.18, +4.14]. This does not establish an improvement against this honest opponent. It also gives no indication of the large gain seen against the original DOS deployment distribution. A null result is not proof that the policies are equivalent.

Each arm played 1,400 Classic games across seven forced-army families, with 100 complete side-swapped pairs per family. The same physical armies and move seeds were used in both arms. The native control and the honest guarded reference use the same movement behavior in this forced-army setting; their 50% control score is a useful consistency check. This experiment evaluates move decisions on those armies, rather than policy-owned deployment strength.

Template results were 704 wins, 33 draws and 663 losses; control results were 689 wins, 22 draws and 689 losses. All 2,800 games completed without engine errors, so there is no missing-score ambiguity. All 700 pairs enter the comparison. Directions were 142 positive, 124 negative and 434 tied pairs (exact two-sided sign p=0.297). This is a direction diagnostic, not a mean-effect null test. The finite-cohort score difference is exactly +1.46 points; the confidence interval describes sampling uncertainty rather than missing outcomes.

The source-informed 80% template / 20% uniform-background prior uses public moves and disclosures only. It was designed around DOS formations, and its background approximates the procedural branch. The honest opponent in this experiment uses the supplied stress-family armies, so the original DOS source distribution is deliberately misspecified. This is a useful separate generality check, not an independent replication of the DOS strength claim. No policy or prior was tuned on this cohort.

Recorded batch execution was 31.27 seconds for the native control and 123.41 for template beliefs, about 3.95 times as much. Different game lengths and concurrent load affect totals; these are not controlled per-decision timings. The result also shows why the small total-time overhead in DOS matches cannot be treated as the isolated cost of inference: DOS emulation dominates that context.
