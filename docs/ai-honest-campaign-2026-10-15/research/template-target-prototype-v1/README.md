# Opt-in Q24 template-prior target prototype

The actual Commander X16 program links and runs this honest prior in a separate RAM bank. Three tested layouts reproduce the native C prototype's96 decisions, probabilities, and signed capture-value cache exactly, using synchronized per-turn RNG input. The third32-decision trace also compares output RNG state exactly. Music remains active and the inference/runtime gateways restore the calling bank. This qualifies a research prototype for an independent strength test; it is not a production promotion or a claim that the standard build already supports the feature.

`AI_TEMPLATE_PRIOR_Q24` is default off. The final default build produces byte-identical FELDMARS.PRG, AI.BIN, MISSION.BIN and PLAY.BIN to HEAD without these hooks. It rejects combination with AI_BELIEF_PRIORS or AI_BACKROW_PRIOR. Normal Classic alone uses the prior. Easy/Hard full public histories and late-root disabled-model fixtures match macro-off moves and RNG on 172 checks. Other rules are tested only for mechanical fallback.

The prior remains the fixed original Colonel distribution: eight template/mirror point masses of .1 each, plus .2 uniform legal-army background. Publicly disclosed origin ranks and public movement eliminate incompatible templates. Every compatible exact template has likelihood one. Background evidence is the without-replacement rank likelihood, followed by the probability that the still-unknown moved origins are mobile. No enemy concealed rank is read. Hidden nibble mutation tests, all eight template arrays, both side mappings, captured-origin history, first Blue move after Red quiet/long-Scout/capture events, and invalid/late history cases are covered by the native oracle suite.

The complete initial deployment establishes origin history before the first public move. Bank24 already retains captured origins, so an exporter can reconstruct the required 40 known-rank/movement bytes and 40 current-square bytes without inventing capture history. Late resets with no complete opening, loaded games, and custom positions use native counts. The actual developer custom-position path enters `play_resume`, calls the explicit forget gateway, and reaches its first AI decision with HISTORY status and valid=0. Loaded games use that same resume path; there is no save-format change. A guarded additional history-validity byte is included in AI test-state serialization.

The inference bank computes Q24 background evidence and fixed-point posterior masses, then allocates integer Flag/Bomb marginals with exact global Q12 totals and per-origin capacity at most4096. It builds capture expectations for all actor ranks. Remaining mobile rank probabilities remain exchangeable; this is the same functional approximation as the frozen spatial Flag/Bomb driver. Native score and goal planning use the resulting expectations; public known and moved targets retain native handling. Miner and Spy worth still depends on public enemy Bomb/Marshal losses. Signed numerator division uses explicit nonnegative magnitude and restored sign to avoid cc65 unsigned promotion and negative-constant rounding differences.

This is a new numerical policy. Q24 flooring and origin-index rather than board-square tie ordering can move a marginal by one Q12 unit. Across the fixed historical140root development selection,56 roots differ in marginals by at most1/4096, and zero root choices differ from the frozen floating policy. All1,940 replayed own decisions report READY, with zero quantization fallbacks. The six native oracle tests cover982 contexts;76 exhibit rounding differences, maximum1LSB. These tests establish a measured numerical bridge, not equivalence over every possible public history or strength on validation games.

## Actual target budget and experimental recipe

The standard full link still overflows MAIN by232bytes. `relocated_link.py` supplies an isolated experimental build recipe; it does not edit the production builder, installed compiler, or installed libraries. It extracts14 newly required arithmetic runtime objects from the pinned installed cx16.lib and renames each object's CODE segment to the same-length B25C name. The raw/transformed object hashes, replacement byte offsets, imports, exports and segment layouts are recorded. Objects have no non-CODE storage, and shared baseline helpers remain in MAIN. All24 generated-C references to relocated exports occur in BELIEFCODE; MAIN gateways, AI hooks and mission exporter have none. Baseline runtime dependency closure was already present before these new objects. Imported zero-page state remains unbanked. The final linked free space is MAIN84B, AI81B, mission245B, play154B and inference1379B.

Three real emulator traces,32decisions each and both armies, verify the opening22→24→22 history gateway, decision23→24→23→25→23→22 bank restoration, actual execution of a relocated long comparison helper in bank25, exact native Q12/cache/move parity, and active/changing PSG music. All96 synchronize input RNG; the third32 also compare output RNG state through a private query-only native observer. Its exact engine diff and hashes are frozen separately. Final-source link binaries are byte-identical to the audio-tested runtime. The minimum untouched software-stack canary is996bytes of the reserved1KiB in these traces; this is measured coverage, not a bound over all positions.

Maximum observed whole-AI work is11,808,584cycles, about1.48seconds at8MHz; preparation is8,717,115cycles, about1.09seconds. This cost is a material target limitation. A future separately versioned hypothesis could reuse inference for unchanged public origin evidence and unchanged dynamic worth inputs, but this prototype deliberately recomputes and has not been silently optimized.
