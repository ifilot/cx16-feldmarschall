Overlay 6 placement driver (ovl6:0C7B..1D1A)
================================================

The reconstructed `placement_driver` in `reconstruction/ovl6/PLAC.C` matches the
original 4,255-byte routine in the controlled DOS composition fixture. The
verifier links the original instructions at their original offsets, preserves
non-call bytes exactly, checks every rebound RNG/setup call target, and checks
the 7,000h-byte DGROUP reservation and immutable input hashes.

The fixture runs 24 deterministic seeds for each DS:3E90 word value 0 through
5. It compares DS:1800..5FFF byte for byte after execution, all RNG results and
call counts, each setup callback's count, argument pair and RNG count at the
call, and search callback counts. It also checks the original 09A1 helper
against the C shape predicate in a separate 2,560-case matrix. The matrix
covers every target coordinate in rows 1..4 and columns 1..10, all 16
combinations of neighboring words set to 11 or 4, target marker values 0 and
1, and target words 4 and 11. It asserts the expected result for each case,
observes 224 true and 2,336 false results, and compares DS:1800..5FFF before
and after each raw and C call. In row 4 the south probe is a lake-column test;
for other rows it reads the neighbor word.

During differential work, seed coverage exposed two source mismatches. The
row-1 edge branch that writes three remaining value-11 cells also decrements
the corresponding local count by three. In the rank-8 relocation section,
the original overwrites its chosen-column local with the first destination
column; the later separation check uses that destination. The C predicate for
09A1 treats the four lake columns specially only when the south neighbor is
beyond row 4. The final verifier passes after these corrections.

Raw-side helper boundaries are original ovl6:03F0, 09A1, 0AD2 and resident
C07E bodies; RNG call sites are redirected only to wrappers around the exact
resident RNG body. The C side composes reconstructed SEARCH, SETUP, BOX, ADJ,
RNG, and the placement shape predicate. This is a controlled composition
result, not evidence for full game-start behavior or for semantic names of
fields beyond their literal addresses and values. The setup and fixed lower
board template are modeled by separate initializer work.

Machine-readable hashes, exact linked-body checks, case details, and limits:
`build/ovl6-placement/verification.json` (generated by
`scripts/verify_ovl6_placement.py`).
