# Cycle 26: independent validation confirms native formation beliefs

The frozen native template-belief policy retained its improvement on fresh seeds: 37.97% scored outcome against 18.78% for the same existing native move policy with validated deployment. The single primary matched-pair effect was +19.32 percentage points, with a 95% paired bootstrap interval of [+15.28, +23.36]. This validates a substantial improvement for this opponent and deployment distribution. It does not establish a 50% match against DOS, generality to different opponents, or readiness for the CX16 target.

The candidate and control were frozen before these 2,000 attempted Classic games. Each arm used 1,000 games on 500 side-swapped pairs, fresh move/setup seeds and the same original DOS armies. The policy, model, prior mixture and coefficients were not retuned after screening or during validation. Both use the deployment mixture already present in the CX16 game; the treatment is the candidate's public formation beliefs, rather than a new production deployment.

Candidate results were 276 wins, 180 draws, 508 losses and 36 unscored original DOS errors; the control recorded 135 wins, 73 draws, 705 losses and 87 errors. The primary comparison uses 396 pairs complete in both arms. Its additional retained 98.3333% interval is [+14.46, +24.31], while the preregistered primary interval is 95%. Pair directions were 202 positive, 71 negative and 123 tied (exact two-sided sign p=9.92e-16). This direction diagnostic is not a mean-effect null test.

All 123 error prefixes remain preserved and errors are excluded from official standings. Assigning each error game's unknown score any value in [0,1] gives all-attempt score bounds of [36.60%, 40.20%] for the candidate and [17.15%, 25.85%] for the control. The finite-cohort treatment effect remains positive throughout [+10.75, +23.05] percentage points. These are missing-outcome bounds for this cohort, not confidence intervals; the lower candidate error incidence remains relevant when interpreting official scores.

The honest source-informed prior assigns 80% mass to eight original Colonel template/mirror formations and 20% to a uniform legal-army background. Public moves and disclosed ranks update consistency; the background approximates rather than reproduces the actual procedural branch. The native planner receives public Flag/Bomb probabilities, not concealed enemy ranks, actual enemy setup or private setup seeds. The original DOS opponent retains its registered information advantage. Side swapping rotates both armies 180 degrees so the exact original DOS-local formation is preserved.

Recorded execution was 954.54 seconds for the control and 980.50 for the candidate, about 2.7% more batch wall time for candidate. Different game lengths and concurrent load affect those totals; this is not a controlled per-decision cost comparison. The result remains a desktop prototype: the native belief-prior interface overflows the current CX16 AI bank by 1,198 bytes, and its public belief driver runs in Python. Porting requires memory/layout work, as preserved under ../research/native-belief-target-fit/.

All 2,000 games pass Python and native every-state replay, with Qt captures and independent frozen owner/original-generator setup audits. The original deployment machine code and emulator are frozen and reproduced. Move RNG is independently reseeded by the existing adapter rather than continued from the original interactive game's post-deployment state; the experiment retains that explicit boundary. No policy, model, source snapshot or registry ID changes. Production remains unchanged; the next frozen tests address deployment interaction and honest-opponent generality.
